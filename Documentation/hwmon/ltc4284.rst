Kernel driver ltc4284
=====================

Supported chips:

  * Analog Devices LTC4284

    Prefix: 'ltc4284'

    Addresses scanned: - I2C 0x14 - 0x15

    Datasheet:

        https://www.analog.com/media/en/technical-documentation/data-sheets/ltc4284.pdf

Author:

 * Carlos Jones Jr <carlosjr.jones@analog.com>
 * Alexis Czezar C Torreno <alexisczezar.torreno@analog.com>

Description
-----------

The LTC4284 is a high power negative voltage hot swap controller with energy
monitor, designed for -48V distributed power systems supporting up to 2500W
applications. The device drives two external N-channel MOSFETs to allow a board
to be safely inserted and removed from a live backplane. The dual-gate,
multi-mode drivers optimize the MOSFET safe operating area (SOA) for a variety
of power levels.

The LTC4284 features an I2C interface and onboard gear-shift ADC that allow
monitoring of board current, voltage, power, energy, and fault status. The
device supports four operation modes: single driver, parallel, high stress
staged start, and low stress staged start modes. An included EEPROM provides
black-box capturing and nonvolatile configuration of fault behavior.

DebugFs entries
---------------

The chip also has a fault log register where failures can be logged. Hence,
as these are logging events, we give access to them in debugfs. Note that
even if some failure is detected in these logs, it does not necessarily mean
that the failure is still present. These logs can be cleared by writing in
the proper reset_history attribute.

.. warning:: The debugfs interface is subject to change without notice
             and is only available when the kernel is compiled with
             ``CONFIG_DEBUG_FS`` defined.

``/sys/kernel/debug/ltc4284-[device]/``
contains the following attributes:

======================== ==========================================
in0_ov_fault_log         Set to 1 by an overvoltage fault occurring
in0_uv_fault_log         Set to 1 by an undervoltage fault occurring
curr1_oc_fault_log       Set to 1 by an overcurrent fault occurring
fet_bad_fault_log        Set to 1 when a FET-BAD fault occurs
fet_short_fault_log      Set to 1 when a FET-short fault is detected
pgi_fault_log            Set to 1 by a power good input fault occurring
power_failed_log         Set to 1 when power failed fault occurs
ext_fault_log            Set to 1 by an external fault occurring
======================== ==========================================
