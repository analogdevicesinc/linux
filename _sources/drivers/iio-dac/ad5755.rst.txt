AD5755
======

AD5755 IIO Multi-Channel DAC Linux Driver.

Supported Devices
-----------------

- :adi:`AD5735`
- :adi:`AD5737`
- :adi:`AD5755`
- :adi:`AD5755-1`
- :adi:`AD5757`

Evaluation Boards
-----------------

- :adi:`EVAL-AD5755SDZ`
- :adi:`EVAL-AD5755-1SDZ`
- :adi:`EVAL-AD5757SDZ`

Reference Circuits
~~~~~~~~~~~~~~~~~~

- :adi:`CN0198`
- :adi:`CN0328`

Description
-----------

This is a Linux industrial I/O (:external+system-level:ref:`iio`) subsystem
driver, targeting multi-channel serial interface DACs. The industrial I/O
subsystem provides a unified framework for drivers for many different types of
converters and sensors using a number of different physical interfaces (i2c,
spi, etc). See :external+system-level:ref:`iio` for more information.

Kernel configuration
~~~~~~~~~~~~~~~~~~~~

Configure kernel with ``make menuconfig`` (alternatively use ``make xconfig`` or
``make qconfig``)

.. note::

   The AD5755 Driver depends on **CONFIG_SPI**

Depending on the converter IC used, you may need to set the modalias
accordingly, matching your part name. It may also required to adjust
max_speed_hz. Please consult the datasheet, for maximum spi clock supported by
the device in question.

.. code-block:: c

   static struct spi_board_info board_spi_board_info[] __initdata = {
   #if IS_ENABLED(CONFIG_AD5755)
       {
           /* the modalias must be the same as spi device driver name */
           .modalias = "ad5755", /* Name of spi_driver for this device */
           .max_speed_hz = 1000000,     /* max spi clock (SCK) speed in HZ */
           .bus_num = 0, /* Framework bus number */
           .chip_select = 3, /* Framework chip select */
           .mode = SPI_MODE_2,
       },
   #endif
   };

.. code:: c

   static int __init board_init(void)
   {
       [--snip--]

       spi_register_board_info(board_spi_board_info, ARRAY_SIZE(board_spi_board_info));

       [--snip--]

       return 0;
   }
   arch_initcall(board_init);

Basic operation
~~~~~~~~~~~~~~~

Show scale
^^^^^^^^^^

**Description:** /sys/bus/iio/devices/iio:deviceX/out_voltageY_scale
/sys/bus/iio/devices/iio:deviceX/out_currentY_scale

Apply the relevant offset before scale. Voltage channels produce millivolts;
current channels produce milliamps. The offset attributes are
out_voltageY_offset or out_currentY_offset, not out_offsetY_raw.

Read the scale for a channel that actually exists; replace ``X`` with the
IIO device index and select the registered voltage or current channel:

.. code-block:: sh

   DEV=/sys/bus/iio/devices/iio:deviceX
   cat "$DEV/out_current0_scale"
   # Only if channel 2 is configured for voltage output:
   cat "$DEV/out_voltage2_scale"


Calibration controls
""""""""""""""""""""

The per-channel ``out_voltageY_calibscale`` or ``out_currentY_calibscale``
attribute accesses the hardware gain register. For AD5755/AD5757, the driver
accepts integer gain codes from 0 to 65535.

The corresponding ``out_voltageY_calibbias`` or ``out_currentY_calibbias``
attribute accesses the hardware offset-calibration register. For AD5755/AD5757,
the driver adds 32768 before writing the register, accepting signed codes
from -32768 to 32767. This calibration control is distinct from the nominal
IIO ``*_offset`` conversion attribute.

The AD5735/AD5737 use an additional four-bit shift for calibration-register
access, so their calibration codes differ from the AD5755/AD5757 codes.

Show offset
~~~~~~~~~~~

The attributes are ``out_voltageY_offset`` and ``out_currentY_offset``.
They express the nominal conversion offset in raw-code units, applied before
the corresponding voltage or current scale:

.. code-block:: sh

   cat "$DEV/out_current0_offset"
   # Only if channel 2 is configured for voltage output:
   cat "$DEV/out_voltage2_offset"

Set channel Y output code
~~~~~~~~~~~~~~~~~~~~~~~~~

Write an unscaled DAC code to the registered ``out_voltageY_raw`` or
``out_currentY_raw`` attribute.

Without calibration correction, the output is
``voltage_mV = (raw + offset) × scale`` for a voltage channel, or
``current_mA = (raw + offset) × scale`` for a current channel.

Enable power down mode for the device
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

/sys/bus/iio/devices/iio:deviceX/out_voltageY_powerdown
/sys/bus/iio/devices/iio:deviceX/out_currentY_powerdown

**Description:** Writing 1 causes channel Y to enter power down mode. Clearing
returns to normal operation.

::

   root:/sys/devices/platform/bfin-spi.0/spi0.3/iio:device0> echo 1 > out_voltage2_powerdown
   root:/sys/devices/platform/bfin-spi.0/spi0.3/iio:device0> cat out_voltage2_powerdown
   1
   root:/sys/devices/platform/bfin-spi.0/spi0.3/iio:device0> echo 0 > out_voltage2_powerdown
   root:/sys/devices/platform/bfin-spi.0/spi0.3/iio:device0> cat out_voltage2_powerdown
   0
