AD4170
======

AD4170 24-Bit Sigma-Delta ADC with Integrated PGA Linux Driver.

Supported Devices
-----------------

This driver supports the

- :adi:`AD4170`

Evaluation Boards
-----------------

- :adi:`EVAL-AD4170`

Description
-----------

This is a Linux industrial I/O (:external+system-level:ref:`iio`) subsystem
driver, targeting single channel serial interface ADCs. The industrial I/O
subsystem provides a unified framework for drivers for many different types of
converters and sensors using a number of different physical interfaces (i2c,
spi, etc). See :external+system-level:ref:`iio` for more information.

Adding Linux driver support
---------------------------

Devicetree configuration
~~~~~~~~~~~~~~~~~~~~~~~~

The binding requires ``compatible``, ``reg``, ``avdd-supply``, ``iovdd-supply``,
``spi-cpol`` and ``spi-cpha``. Each channel node uses either ``diff-channels``
for a differential pair, or ``single-channel`` with ``common-mode-channel``
for a pseudo-differential input, plus ``adi,reference-select`` to pick the
reference source. Input numbers 0-8 are the AIN pins; higher numbers select
internal nodes such as the temperature sensor (17), REFOUT (29) or DGND (24).

.. code-block:: dts

   #include <dt-bindings/interrupt-controller/irq.h>
   spi {
       #address-cells = <1>;
       #size-cells = <0>;

       adc@0 {
           compatible = "adi,ad4170-4";
           reg = <0>;
           spi-max-frequency = <20000000>;
           spi-cpol;
           spi-cpha;
           avdd-supply = <&avdd>;
           iovdd-supply = <&iovdd>;
           interrupts = <25 IRQ_TYPE_EDGE_FALLING>;
           interrupt-names = "dig_aux1";
           #address-cells = <1>;
           #size-cells = <0>;

           /* AIN29 (REFOUT) vs AIN24 (DGND) */
           channel@0 {
               reg = <0>;
               diff-channels = <29 24>;
               adi,reference-select = <2>;
           };

           /* AIN0 vs AIN24 (DGND) */
           channel@1 {
               reg = <1>;
               diff-channels = <0 24>;
               bipolar;
               adi,reference-select = <2>;
           };

           /* AIN3 vs AIN4 */
           channel@2 {
               reg = <2>;
               diff-channels = <3 4>;
               bipolar;
               adi,reference-select = <2>;
           };
       };
   };

Sensor excitation for load cell, RTD and thermocouple setups is described
with ``adi,sensor-type``, ``adi,excitation-pin-N``,
``adi,excitation-current-N-microamp`` and ``adi,excitation-ac``; see the
binding examples for complete weigh-scale, RTD and thermocouple channel
nodes. Changing a channel's ``filter_type`` can change the set of valid
output data rates, so read back ``sampling_frequency`` after switching
filters.

Basic operation
~~~~~~~~~~~~~~~

Show channel scale, offset, sampling_frequency, calibbias, calibscale
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Set ``CHAN`` to the differential channel name reported under the device's
sysfs directory, e.g. ``in_voltage29-voltage24``.

.. code-block:: sh

   DEV=/sys/bus/iio/devices/iio:deviceX
   CHAN=in_voltage29-voltage24
   cat "$DEV/${CHAN}_scale"
   cat "$DEV/${CHAN}_offset"
   cat "$DEV/${CHAN}_raw"
   cat "$DEV/${CHAN}_calibbias"
   cat "$DEV/${CHAN}_calibscale"
   cat "$DEV/${CHAN}_sampling_frequency"

The voltage is ``U_mV = (raw + offset) × scale``; the offset is in raw-code
units. Bipolar conversion values are sign-extended by the driver.
