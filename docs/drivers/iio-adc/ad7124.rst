AD7124
======

AD7124 IIO Sigma-Delta ADC Linux Driver.

Supported Devices
-----------------

This driver supports the

- :adi:`AD7124-4`
- :adi:`AD7124-8`

Evaluation Boards
-----------------

- :adi:`EVAL-AD7124-4`
- :adi:`EVAL-AD7124-8`

Description
-----------

This is a Linux industrial I/O (:external+system-level:ref:`iio`) subsystem driver for the
AD7124-4 and AD7124-8 multiplexed sigma-delta ADCs. Voltage channels are
configured from devicetree channel nodes. The industrial I/O subsystem provides
a unified framework for drivers for many different types of converters and
sensors using a number of different physical interfaces (i2c, spi, etc). See
:external+system-level:ref:`iio` for more information.

Basic operation
~~~~~~~~~~~~~~~

Show channel scale and offset
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

**Description:** Scales and offsets to be applied to in_voltagex_voltagey_raw in
order to obdatin the measured voltage in millivolts

::

   root:/sys/bus/iio/devices/iio:device0> cat in_voltage0-voltage1_scale
   0.000149011
   root:/sys/bus/iio/devices/iio:device0> cat in_voltage0-voltage1_offset
   0
   root:/sys/bus/iio/devices/iio:device0> cat in_voltage0-voltage1_raw
   2679470

**Description:** Channel Ainp0-Ainm1 is configured as unipolar, with a gain of
1: U_mV = (raw + offset) × scale = (2679470 + 0) × 0.000149011 ≈ 399.27 mV.

.. code-block:: text

   root:/sys/bus/iio/devices/iio:device0> cat in_voltage2-voltage3_scale
   0.000298023
   root:/sys/bus/iio/devices/iio:device0> cat in_voltage2-voltage3_offset
   -8388608
   root:/sys/bus/iio/devices/iio:device0> cat in_voltage2-voltage3_raw
   9716211

**Description:** Channel Ainp2-Ainm3 is configured as bipolar, with a gain of
1: U_mV = (raw + offset) × scale = (9716211 - 8388608) × 0.000298023 ≈
395.66 mV.

Set sampling frequency
~~~~~~~~~~~~~~~~~~~~~~

**Description:** The output data rate depends on the master clock frequency
(fclk) which in turn determines the power mode:

-  The sampling frequency depends on the filter and clock: fCLK/(32 × N × FS),
   with N = 3 for sinc3, N = 4 for sinc4, additional averaging for sinc1
   combinations, and FS clamped to 1..2047. Post filters have fixed rates.
   Read ``sampling_frequency`` back after writing it.

::

   root:/sys/bus/iio/devices/iio:device0> cat in_voltage0-voltage1_sampling_frequency
   10
   root:/sys/bus/iio/devices/iio:device0> cat in_voltage2-voltage3_sampling_frequency
   960
   root:/sys/bus/iio/devices/iio:device0> echo 2400 > in_voltage0-voltage1_sampling_frequency
   root:/sys/bus/iio/devices/iio:device0> cat in_voltage0-voltage1_sampling_frequency
   2400
   root:/sys/bus/iio/devices/iio:device0> echo 5000 > in_voltage2-voltage3_sampling_frequency
   root:/sys/bus/iio/devices/iio:device0> cat in_voltage2-voltage3_sampling_frequency
   4800
