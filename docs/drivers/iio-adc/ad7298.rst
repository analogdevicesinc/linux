AD7298
======

AD7298 IIO Multi-Channel ADC Linux Driver.

Supported Devices
-----------------

- :adi:`AD7298`

Evaluation Boards
-----------------

- :adi:`EVAL-AD7298SDZ`

Description
-----------

This is a Linux industrial I/O (:external+system-level:ref:`iio`) subsystem
driver, targeting multi channel serial interface ADCs. The industrial I/O
subsystem provides a unified framework for drivers for many different types of
converters and sensors using a number of different physical interfaces (i2c,
spi, etc). See :external+system-level:ref:`iio` for more information.

Reference voltage
~~~~~~~~~~~~~~~~~

The driver selects an external reference when a ``vref`` regulator is supplied
and enabled. Otherwise it uses the internal 2.5 V reference.

.. include:: /include/platform-and-bus-model.rst
   :start-after: .. start-declaring-spi-slave-devices
   :end-before: .. end-declaring-spi-slave-devices

Depending on the converter IC used, you may need to set the modalias
accordingly, matching your part name. It may also required to adjust
max_speed_hz. Please consult the datasheet, for maximum spi clock supported by
the device in question.

.. code:: c

   static struct spi_board_info board_spi_board_info[] __initdata = {
   #if defined(CONFIG_AD7298) || \
       defined(CONFIG_AD7298_MODULE)
       {
           .modalias = "ad7298",
           .max_speed_hz = 1000000,     /* max spi clock (SCK) speed in HZ */
           .bus_num = 0,
           .chip_select = 3, /* CS, change it for your board */
           .controller_data = &spi_ad7298_chip_info,
           .mode = SPI_MODE_1,
       },
   #endif
   };

.. code:: c

   static int __init board_init(void)
   {
       [--snip--]

       spi_register_board_info(board_spi_board_info, ARRAY_SIZE(board_spi_board_info));

       [--snip--]

       return 0;
   }
   arch_initcall(board_init);

Basic operation
~~~~~~~~~~~~~~~

Show scale
^^^^^^^^^^

**Description:** scale to be applied to in0_raw in order to obtain the measured
voltage in millivolts.

::

   root:/sys/devices/platform/bfin-spi.0/spi0.3/device0> cat in_scale
   0.610

Show internal temperature
~~~~~~~~~~~~~~~~~~~~~~~~~

**Description:** Shows high accuracy band gap temperature sensor temperature in
milli degrees Celsius.

Read temperature directly, with buffering stopped, in the correct IIO device
directory. Temperature cannot be included in the buffered voltage scan; the
result below is in millidegrees Celsius.

.. code-block:: bash

   set -eu
   raw=$(cat in_temp0_raw)
   offset=$(cat in_temp0_offset)
   scale=$(cat in_temp0_scale)
   awk -v raw="$raw" -v offset="$offset" -v scale="$scale" 'BEGIN { printf "%.3f mC\n", (raw + offset) * scale }'

For example, an output of ``29750.000 mC`` corresponds to **T** = **29.75 °C**.

Show channel 0 measurement
~~~~~~~~~~~~~~~~~~~~~~~~~~

**Description:** Raw unscaled voltage measurement on channel 0

::

   root:/sys/devices/platform/bfin-spi.0/spi0.3/device0> cat in0_raw
   2158

The voltage is ``in_voltage0_raw`` × ``in_voltage_scale``. With the internal
2.5 V reference, scale = 2500/4096 ≈ 0.610351562 mV/code, so a raw value of
2158 is approximately 1317.14 mV.

Buffer management
~~~~~~~~~~~~~~~~~

Use ``/sys/bus/iio/devices/iio:deviceX/buffer`` (or ``buffer0``) for
buffer controls, ``scan_elements/in_voltageN_en`` for voltage scan selection,
and ``/dev/iio:deviceX`` for sample data. Replace ``X`` with the actual IIO
device index. These commands inspect metadata; they do not assert capture
results:

.. code-block:: sh

   DEV=/sys/bus/iio/devices/iio:deviceX
   cat "$DEV/name"
   ls "$DEV/buffer"
   ls "$DEV/scan_elements"

Voltage samples are big-endian unsigned 12-bit values in 16-bit storage.
Read each channel's ``*_type`` and ``*_index`` metadata, and account for
alignment padding if the timestamp is enabled.

.. include:: /include/iio-snippets.rst
   :start-after: .. start-buffer-management
   :end-before: .. end-buffer-management

For example, inspect the first voltage channel and timestamp:

.. code-block:: sh

   cat "$DEV/scan_elements/in_voltage0_type"
   cat "$DEV/scan_elements/in_voltage0_index"
   cat "$DEV/scan_elements/in_timestamp_type"
   cat "$DEV/scan_elements/in_timestamp_index"
