AD5933
======

AD5933 IIO Impedance Converter and Network Analyzer.

Supported Devices
-----------------

- :adi:`AD5933`
- :adi:`AD5934`

Evaluation Boards
-----------------

- :adi:`EVAL-AD5933EBZ`

Reference Circuits
~~~~~~~~~~~~~~~~~~

- :adi:`CN0217`
- :adi:`CN0349`

Description
-----------

This is a Linux industrial I/O (:external+system-level:ref:`iio`) subsystem
driver, targeting Impedance Converters and Network Analyzers. The industrial I/O
subsystem provides a unified framework for drivers for many different types of
converters and sensors using a number of different physical interfaces (i2c,
spi, etc). See :external+system-level:ref:`iio` for more information.

Platform-data configuration
~~~~~~~~~~~~~~~~~~~~~~~~~~~

Example platform device initialization
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

The driver obtains its supply voltage from a regulator named ``vdd`` and uses
that voltage to determine the excitation ranges. Register the actual board
supply through the regulator framework and provide a clock lookup named
``mclk`` when using an external master clock. The
``ad5933_platform_data`` structure is not consumed by this driver.

AD5933 can use its internal oscillator when no usable external clock is
provided. AD5934 requires an external master clock: its board configuration
must provide the actual MCLK source. The driver's AD5933 internal-clock
fallback does not make an AD5934 board usable without that source.

The registration fragment below assumes the board has already registered
these regulator and clock resources; it does not define board-specific
supply voltages or clock rates.

.. include:: /include/platform-and-bus-model.rst
   :start-after: .. start-declaring-i2c-devices
   :end-before: .. end-declaring-i2c-devices

Depending on the converter IC used, you may need to set the I2C_BOARD_INFO name
accordingly, matching your part name.

.. list-table::
   :header-rows: 1

   * - ADI part number
     - I2C_BOARD_INFO Name
   * - AD5933
     - ad5933
   * - AD5934
     - ad5934

.. code-block:: c

   static struct i2c_board_info __initdata board_i2c_board_info[] = {
   #if defined(CONFIG_AD5933) || defined(CONFIG_AD5933_MODULE)
       {
           I2C_BOARD_INFO("ad5933", 0x0D),
       },
   #endif
   };

.. code:: c

   static int __init board_init(void)
   {
       [--snip--]

       i2c_register_board_info(0, board_i2c_board_info,
                   ARRAY_SIZE(board_i2c_board_info));
       [--snip--]

       return 0;
   }
   arch_initcall(board_init);

Basic operation
~~~~~~~~~~~~~~~

Show available input scales
^^^^^^^^^^^^^^^^^^^^^^^^^^^

**Description:** /sys/bus/iio/devices/iio:deviceX/in_voltage0_scale_available
List available input scales. Programmable gain amplifier (PGA) options.

::

   root:/sys/bus/iio/devices/iio:deviceX> cat in_voltage0_scale_available
   1 0.2

Set sweep start frequency
~~~~~~~~~~~~~~~~~~~~~~~~~

**Description:** /sys/bus/iio/devices/iio:deviceX/out_altvoltage0_frequency_start

Frequency sweep start frequency in Hz.

::

   root:/sys/bus/iio/devices/iio:deviceX> echo 15000 > out_altvoltage0_frequency_start
   root:/sys/bus/iio/devices/iio:deviceX> cat out_altvoltage0_frequency_start
   14999

Set frequency increment
~~~~~~~~~~~~~~~~~~~~~~~

**Description:** /sys/bus/iio/devices/iio:deviceX/out_altvoltage0_frequency_increment
Frequency increment in Hz (step size) between consecutive frequency points along
the sweep.

::

   root:/sys/bus/iio/devices/iio:deviceX> echo 200 > out_altvoltage0_frequency_increment

Set number of frequency points
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

**Description:** /sys/bus/iio/devices/iio:deviceX/out_altvoltage0_frequency_points
Number of frequency points (steps) in the frequency sweep. This value, in
conjunction with the out_altvoltage0_frequency_start and the
out_altvoltage0_frequency_increment, determines the frequency sweep range for the sweep
operation.

::

   root:/sys/bus/iio/devices/iio:deviceX> echo 100 > out_altvoltage0_frequency_points
   root:/sys/bus/iio/devices/iio:deviceX> cat out_altvoltage0_frequency_points
   100

Set number of settling time cycles
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

**Description:** /sys/bus/iio/devices/iio:deviceX/out_altvoltage0_settling_cycles
Number of output excitation cycles (settling time cycles) that are allowed to
pass through the unknown impedance, after each frequency increment, and before
the ADC is triggered to perform a conversion sequence of the response signal.

::

   root:/sys/bus/iio/devices/iio:deviceX> echo 15 > out_altvoltage0_settling_cycles
   root:/sys/bus/iio/devices/iio:deviceX> cat out_altvoltage0_settling_cycles
   15

Show available output ranges
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

**Description:** /sys/bus/iio/devices/iio:deviceX/out_altvoltage0_scale_available
List available output scales/ranges in millivolt.

::

   root:/sys/bus/iio/devices/iio:deviceX> cat out_altvoltage0_scale_available
   1980 970 383 198

Set output range
~~~~~~~~~~~~~~~~

**Description:** /sys/bus/iio/devices/iio:deviceX/out_altvoltage0_raw Sets output
scale/range in millivolt.

::

   root:/sys/bus/iio/devices/iio:deviceX> echo 1980 > out_altvoltage0_raw
   root:/sys/bus/iio/devices/iio:deviceX> cat out_altvoltage0_raw
   1980

Set input scale
~~~~~~~~~~~~~~~

Recalibrate the impedance gain factor whenever the PGA gain, output excitation
voltage, or external current-to-voltage gain resistor changes. A calibration
taken with previous settings must not be reused for the new settings. Ensure
that the receive signal remains within the linear ADC range.

**Description:** /sys/bus/iio/devices/iio:deviceX/in_voltage0_scale Sets input
scale. Controls programmable gain amplifier (PGA).

::

   root:/sys/bus/iio/devices/iio:deviceX> echo 0.2 > in_voltage0_scale
   root:/sys/bus/iio/devices/iio:deviceX> cat in_voltage0_scale
   0.2

Show internal temperature
~~~~~~~~~~~~~~~~~~~~~~~~~

The temperature channel is unindexed and exposes ``in_temp_raw`` and
``in_temp_scale``. Calculate temperature in millidegrees Celsius as raw
multiplied by scale. The on-chip sensor's measurement range is −40°C to +125°C.

Run these commands in the device's sysfs directory:

.. code-block:: sh

   raw=$(cat in_temp_raw)
   scale=$(cat in_temp_scale)
   awk -v raw="$raw" -v scale="$scale" 'BEGIN { print raw * scale }'

Data interpretation
^^^^^^^^^^^^^^^^^^^

.. list-table::
   :header-rows: 1

   * - index
     - datum
     - type
   * - 0
     - **Real Sample** f0
     - signed short 16-bit
   * - 1
     - **Imag Sample** f0
     - signed short 16-bit
   * - [fn \* 2]
     - **Real Sample** fn
     - signed short 16-bit
   * - [fn \* 2] + 1
     - **Imag Sample** fn
     - signed short 16-bit

The buffer contains signed real/imaginary DFT output codes, not impedance in
ohms. Apply application-specific gain/phase calibration to derive impedance; the
driver does not perform that conversion.
