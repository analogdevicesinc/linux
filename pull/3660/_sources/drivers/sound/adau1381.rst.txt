Hardware configuration
""""""""""""""""""""""

Connect the STAMP SPORT 0 port (P6) to the EVAL-ADAU1X81 Control port(J1) and
Serial Data Interface(J4) headers.

Note that the SPORT has separate signals for the capture and playback clocks,
while the ADAU1381/ADAU1781 uses the same clock signals for both, so the
EVAL-ADAU1X81 clock signal pins need to be connected to two STAMP pins each.

.. list-table::
   :header-rows: 1

   * - STAMP pin
     - EVAL-ADAU1X81 pin
     - Function
   * - P6-26 (SPORT 0 - PJ2_SCL)
     - J1-1
     - I2C SCL
   * - P6-24 (SPORT 0 - PJ3_SDA)
     - J1-3
     - I2C SDA
   * - P6-6 (SPORT 0 - PJ9_TSCLK0), P6-16 (SPORT 0 - PJ6_RSCLK0)
     - J4-7
     - BCLK
   * - P6-11 (SPORT 0 - PJ10_TFS0), P6-7 (SPORT 0 - PJ7_RFS0)
     - J4-5
     - LRCLK
   * - P6-8 (SPORT 0 - PJ8_DR0PRI)
     - J4-9
     - Captrue data
   * - P6-14 (SPORT 0 - PJ11_DT0PRI
     - J4-11
     - Playback data
   * - P6-33
     - J4-2
     - GND

DAI formats and clocks
~~~~~~~~~~~~~~~~~~~~~~

PLL configuration
^^^^^^^^^^^^^^^^^

The ADAU1781 features one PLL:

.. code:: c

   enum adau17x1_pll {
       ADAU17X1_PLL
   };

The PLL input signal is the MCLK signal.

.. code-block:: c

   enum adau17x1_pll_src {
   ADAU17X1_PLL_SRC_MCLK,
   };

The driver checks that the PLL input frequency is 8 MHz to 27 MHz. It then
validates whether the requested output is representable by the PLL divider
fields; it does not enforce an explicit 45.158–49.152 MHz output-range check.
Use a hardware-valid clock plan, normally 45.1584 MHz or 49.152 MHz for the
sample-rate families below. Driver acceptance alone does not validate electrical
limits.

The PLL runs at 1024 times the base sample rate. So for a 48000 Hz based sample
rate you’d normally choose 49152000 Hz for the PLL output frequncey and for a
44100 Hz based sample rate 45158400 Hz.

DAI sysclk
""""""""""

The DAIs can either use the PLL or the MCLK signal as source.

When using the PLL the DAIs rate should be set to the rate of the PLL. When
using MCLK the rate should be set to frequency of the external MCLK signal.

.. code-block:: c

   enum adau17x1_clk_src {
       ADAU17X1_CLK_SRC_PLL_AUTO,
       ADAU17X1_CLK_SRC_MCLK,
       ADAU17X1_CLK_SRC_PLL,
   };

These identifiers are defined in sound/soc/codecs/adau17x1.h; include that
header in the machine driver rather than redeclaring the enum.

The current shared DAI operations have no set_clkdiv callback. For direct MCLK
operation, tell the codec the actual MCLK frequency using
snd_soc_dai_set_sysclk(). For example, a physically supplied 24.576 MHz MCLK
gives a supported ratio of 512 at 48 kHz. This configures the codec’s clock
source; the board must supply that clock and configure the CPU DAI separately.

Example codec initialization callback for a card using that direct-MCLK clock
plan:

.. code-block:: c

   #include <sound/soc.h>
   #include "adau17x1.h" /* sound/soc/codecs/adau17x1.h */

   static int adau1381_mclk_init(struct snd_soc_pcm_runtime *rtd)
   {
       struct snd_soc_dai *codec_dai = snd_soc_rtd_to_codec(rtd, 0);

       return snd_soc_dai_set_sysclk(codec_dai, ADAU17X1_CLK_SRC_MCLK,
                                    24576000, SND_SOC_CLOCK_IN);
   }

Assign adau1381_mclk_init to the card’s DAI-link init callback. The following
PLL-based example is an alternative clock plan; do not combine its clock
selection with this direct-MCLK setup.

Example DAI configuration
^^^^^^^^^^^^^^^^^^^^^^^^^

Alternative PLL-based machine-driver fragment: this example assumes a physically
supplied 12.288 MHz MCLK, with the codec providing BCLK/LRCLK and the CPU
receiving them. Component names are board-specific placeholders. Attach the DAI
link to the board’s sound card.

.. code-block:: c

   #include <sound/soc.h>
   #include <sound/pcm_params.h>
   #include "adau17x1.h"

   static int bfin_eval_adau1x81_hw_params(struct snd_pcm_substream *substream,
       struct snd_pcm_hw_params *params)
   {
       struct snd_soc_pcm_runtime *rtd = substream->private_data;
       struct snd_soc_dai *cpu_dai = snd_soc_rtd_to_cpu(rtd, 0);
       struct snd_soc_dai *codec_dai = snd_soc_rtd_to_codec(rtd, 0);
       int pll_rate;
       int ret;

       ret = snd_soc_dai_set_fmt(cpu_dai, SND_SOC_DAIFMT_I2S |
               SND_SOC_DAIFMT_NB_NF | SND_SOC_DAIFMT_CBC_CFC);
       if (ret)
           return ret;

       ret = snd_soc_dai_set_fmt(codec_dai, SND_SOC_DAIFMT_I2S |
               SND_SOC_DAIFMT_NB_NF | SND_SOC_DAIFMT_CBP_CFP);
       if (ret)
           return ret;

       switch (params_rate(params)) {
       case 48000:
       case 8000:
       case 12000:
       case 16000:
       case 24000:
       case 32000:
           pll_rate = 48000 * 1024;
           break;
       case 44100:
       case 7350:
       case 11025:
       case 14700:
       case 22050:
       case 29400:
           pll_rate = 44100 * 1024;
           break;
       default:
           return -EINVAL;
       }

       ret = snd_soc_dai_set_pll(codec_dai, ADAU17X1_PLL,
               ADAU17X1_PLL_SRC_MCLK, 12288000, pll_rate);
       if (ret)
           return ret;

       ret = snd_soc_dai_set_sysclk(codec_dai, ADAU17X1_CLK_SRC_PLL, pll_rate,
               SND_SOC_CLOCK_IN);

       return ret;
   }

   static struct snd_soc_ops bfin_eval_adau1x81_ops = {
       .hw_params = bfin_eval_adau1x81_hw_params,
   };

   /* Replace the component names below with the names on the target board. */
   SND_SOC_DAILINK_DEFS(adau1381_link,
       DAILINK_COMP_ARRAY(COMP_CPU("board-i2s")),
       DAILINK_COMP_ARRAY(COMP_CODEC("adau1781.0-0038", "adau-hifi")),
       DAILINK_COMP_ARRAY(COMP_PLATFORM("board-pcm")));

   static struct snd_soc_dai_link bfin_eval_adau1x81_dai = {
       .name = "adau1x81",
       .stream_name = "ADAU1X81",
       .ops = &bfin_eval_adau1x81_ops,
       SND_SOC_DAILINK_REG(adau1381_link),
   };

TDM configuration
^^^^^^^^^^^^^^^^^

The ADAU1381 and ADAU1781 chips have basic TDM support.

-  The number of slots can be either 2, 4 or 8.

-  The total frame length (slots \* slot_width), not the per-slot width, must be
   32, 48, 64, 128 or 256 bits.

-  The slot mask must be either 0x03 (slot 0 and 1), 0x0c (slot 2 and 3), 0x30
   (slot 4 and 5), 0xc0 (slot 6 and 7)

Example TDM configuration:

.. code-block:: c

   ret = snd_soc_dai_set_tdm_slot(codec_dai, 0x30, 0x0c, 8, 32);
