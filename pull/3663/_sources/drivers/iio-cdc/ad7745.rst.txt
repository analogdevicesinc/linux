AD7746
======

AD7746 IIO Capacitance to Digital Converter.

Supported Devices
-----------------

- :adi:`AD7745`
- :adi:`AD7746`
- :adi:`AD7747`

Evaluation Boards
-----------------

- :adi:`EVAL-AD7746EBZ`
- :adi:`EVAL-AD7747EBZ`

Reference Circuits
~~~~~~~~~~~~~~~~~~

- :adi:`CN0346`

Description
-----------

This is a Linux industrial I/O (:external+system-level:ref:`iio`) subsystem
driver, targeting single and multi channel serial interface Capacitance to
Digital Converters. The industrial I/O subsystem provides a unified framework
for drivers for many different types of converters and sensors using a number of
different physical interfaces (i2c, spi, etc). See
:external+system-level:ref:`iio` for more information.

Hardware configuration
----------------------

Use floating capacitive sensors with AD7745/AD7746: both sensor plates must
remain isolated from ground, with the sensor connected between excitation and
capacitance input. AD7747 instead measures sensors with one plate connected to
ground. These variants are not interchangeable in the sensor wiring.

.. figure:: https://wiki.analog.com/_media/resources/tools-software/linux-drivers/iio-cdc/ad7746_eval_lr.jpg
   :width: 600px

Perform channel gain calibration
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

**Description:** Triggers gain calibration on channel in_capacitance0 or
in_capacitance1. For AD7745/AD7746, connect an external full-scale calibration
capacitance to the selected input before starting gain calibration. Power-up or
reset restores the factory gain coefficient; the datasheet specifications apply
to that factory coefficient. On AD7746 the gain-calibration register is shared
by both capacitance channels.

::

   root:/sys/devices/platform/i2c-bfin-twi.0/i2c-0/0-0048/iio:device0> echo 1 > in_capacitance1_calibscale_calibration
   root:/sys/devices/platform/i2c-bfin-twi.0/i2c-0/0-0048/iio:device0> cat in_capacitance1_calibscale
   1.000000

Perform channel offset calibration
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

**Description:** Triggers offset calibration on channel in_capacitance0 or
in_capacitance1

Show channel CIN1(+) measurement
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

**Description:** Raw unscaled capacitance measurement on channel
in_capacitance0_raw

.. list-table::
   :header-rows: 1

   * - ADC Input
     - Channel name
   * - CIN1(+)
     - in_capacitance0_raw
   * - CIN2(+)
     - in_capacitance1_raw
   * - CIN1(+) - CIN1(-)
     - in_capacitance0-capacitance2_raw
   * - CIN2(+) - CIN2(-)
     - in_capacitance1-capacitance3_raw
   * - VIN1
     - in_voltage0_raw
   * - VIN_VDD_MON
     - in_voltage1_supply_raw

::

   root:/sys/devices/platform/i2c-bfin-twi.0/i2c-0/0-0048/iio:device0> cat in_capacitance0_raw
   14914

**U** = *in_capacitance0_raw \* in_capacitance_scale* = 14914 \* 0.000000488 =
**0.007278032 pF**

Show internal temperature measurement
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Read ``in_temp0_raw`` for the internal sensor or ``in_temp1_raw`` for the
external diode. Multiply by the shared ``in_temp_scale`` to obtain temperature
in millidegrees Celsius.

.. list-table::
   :header-rows: 1

   * - ADC Input Channel
     - Channel name
   * - TEMP (internal sensor)
     - in_temp0_raw
   * - TEMP (external sensor diode)
     - in_temp1_raw

Run these commands in the device's sysfs directory to calculate the internal
sensor's temperature from actual readbacks:

.. code-block:: sh

   raw=$(cat in_temp0_raw)
   scale=$(cat in_temp_scale)
   awk -v raw="$raw" -v scale="$scale" 'BEGIN { print raw * scale }'

Set channel common mode offset (CAPDAC)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

**Description:** If known for a device, offset to be added to <type>[Y]_raw
prior to scaling by <type>[Y]_scale in order to obtain value in the <type> units
as specified in <type>[y]_raw documentation.

.. list-table::
   :header-rows: 1

   * - Input
     - CAPDAC
     - Channel name
   * - CIN1(+)
     - CAPDAC(+)
     - in_capacitance0_offset
   * - CIN2(+)
     - CAPDAC(+)
     - in_capacitance1_offset
   * - CIN1(-)
     - CAPDAC(-)
     - in_capacitance0-capacitance2_zeropoint
   * - CIN2(-)
     - CAPDAC(-)
     - in_capacitance1-capacitance3_zeropoint

.. note::

   The AD7745/AD7746 CDC full-scale input range is ±4.096 pF. The part can
   accept a higher capacitance on the input and the common-mode or offset
   (not-changing component) capacitance can be balanced by programmable on-chip
   CAPDACs.

**Example 4pF Offset:** **in_capacitance0_offset** = *Offset /
in_capacitance_scale* = 4pF / 0.000000488 = **8196721**

::

   root:/sys/devices/platform/i2c-bfin-twi.0/i2c-0/0-0048/iio:device0> echo 8196721 > in_capacitance0_offset
   root:/sys/devices/platform/i2c-bfin-twi.0/i2c-0/0-0048/iio:device0> cat in_capacitance0_offset
   8127504

~~~~~~~~~~~~~~~~~~~~~~~~~~~~

**Description:** Write gain coefficient for channel in_capacitance0 or
in_capacitance1 Valid range is between 1.0 and 1.99999999.
