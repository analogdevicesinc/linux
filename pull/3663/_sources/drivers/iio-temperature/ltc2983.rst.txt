LTC2983
=======

LTC2983/LTC2984/LTC2986/LTM2985 Multi-Sensor Digital Temperature Measurement System Driver.

Supported Devices
-----------------

- :adi:`LTC2983`
- :adi:`LTC2984`
- :adi:`LTC2986`
- :adi:`LTM2985`

Evaluation Boards
-----------------

- :adi:`DC2296A`
- :adi:`DC2296A-KIT`

Description
-----------

This is a Linux industrial I/O (:external+system-level:ref:`iio`) subsystem
driver, targeting temperature sensors. The industrial I/O subsystem provides a
unified framework for drivers for many different types of converters and sensors
using a number of different physical interfaces (i2c, spi, etc). See
:external+system-level:ref:`iio` for more information.

Adding Linux driver support
---------------------------

Kernel configuration
~~~~~~~~~~~~~~~~~~~~

Configure kernel with ``make menuconfig`` (alternatively use ``make xconfig`` or
``make qconfig``).

.. note::

   The LTC2983 driver depends **CONFIG_SPI**.

::

   Linux Kernel Configuration
       Device Drivers  --->
       <*>     Industrial I/O support --->
           --- Industrial I/O support
               [--snip--]
                 Temperature sensors --->
           [--snip--]
               -*- Analog Devices Multi-Sensor Digital Temperature Measurement
               System
           [--snip--]

Identify the device
~~~~~~~~~~~~~~~~~~~

::

   root:/sys/bus/iio/devices/iio:device0> cat name
   ltc2983

Basic operation
~~~~~~~~~~~~~~~

Show temperature scale
^^^^^^^^^^^^^^^^^^^^^^

**Description:** Multiply ``in_tempN_raw`` by ``in_temp_scale`` to obtain
millidegrees Celsius when the device is configured for Celsius; divide by 1000
for °C. The driver reports a scale of ``1000/1024``.

The driver does not change the temperature-unit setting and has no
Celsius/Fahrenheit selector.

.. code-block:: text

   root:/sys/bus/iio/devices/iio:device0> cat in_temp_scale
   0.976562500

Show temperature
~~~~~~~~~~~~~~~~

::

   root:/sys/bus/iio/devices/iio:device0> cat in_temp0_raw

Show voltage
~~~~~~~~~~~~

::

   root:/sys/bus/iio/devices/iio:device0> cat in_voltage0_raw

Show Voltage scale
~~~~~~~~~~~~~~~~~~

**Description:** Multiply ``in_voltageN_raw`` by ``in_voltage_scale`` to obtain
millivolts; divide by 1000 for volts. The driver reports ``1000/2^21`` mV/code.

.. code-block:: text

   root:/sys/bus/iio/devices/iio:device0> cat in_voltage_scale
   0.000476837
